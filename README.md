# Sportin

Sportin is a full-stack web application designed to connect athletes, coaches, and sports organizations through a centralized networking platform. It provides a space for users to create professional profiles, discover opportunities, and build meaningful connections within the sports community.

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Cloudinary
